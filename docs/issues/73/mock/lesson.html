The context window is the model’s desk

Tool use kept slipping because this idea was missing. A short conversation, then one question.

Tutor

You know attention: every token looks at every other token. So what happens to the cost when the text gets twice as long?

You

It goes up more than twice, because every token checks every other one.

Tutor

Right, it grows with the square. That’s why every model has a hard limit on how much text it can look at in one go. That limit is the context window. Think of it as a desk: whatever isn’t on the desk, the model can’t see.

Tutor

Now tool use. When a model calls a tool, the result lands back on that same desk. Ten big search results later, what do you think happens?
